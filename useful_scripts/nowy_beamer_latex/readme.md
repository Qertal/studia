# 🎬 Beamer Project Generator

Skrypt `new_beamer_project.sh` służy do szybkiego tworzenia gotowego projektu prezentacji LaTeX (Beamer), z uporządkowaną strukturą katalogów i sensownym szablonem startowym.

---

## 🚀 Jak używać

```bash
./new_beamer_project.sh NAZWA_PROJEKTU
```
W aktualnym srodowisku wystarczy 
new_beamer_project.sh NAZWA_PROJEKTU
aby utworzyło projekt w biezacym folderze
